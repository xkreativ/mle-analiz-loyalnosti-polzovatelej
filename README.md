# Анализ лояльности пользователей Яндекс Афиши

Итоговый проект модуля 2 спринта 7 курса Инженер Машинного Обучения Яндекс Практикума.

## О проекте

В проекте я смотрю, какие пользователи Яндекс Афиши делают повторные заказы. Данные - заказы билетов с июня по октябрь 2024 года.

Сначала анализ был сделан в Jupyter Notebook. Потом я перенес код в класс `DataProcessor` в файле `src/processing.py`. Файл `main.py` запускает весь анализ и выводит отчет в терминал.

Что делает программа:
- загружает данные и переводит выручку из тенге в рубли
- чистит данные (убирает возвраты и выбросы)
- строит профили пользователей
- считает долю вернувшихся пользователей по сегментам
- проверяет две гипотезы
- считает корреляцию phi_k с количеством заказов

## Как запустить

1. Склонировать репозиторий

```
git clone git@github.com:xkreativ/mle-analiz-loyalnosti-polzovatelej.git
cd mle-analiz-loyalnosti-polzovatelej
```

2. Создать виртуальное окружение и установить библиотеки

```
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

3. Скачать данные в папку `data/`

- https://code.s3.yandex.net/datasets/final_tickets_orders_df.csv
- https://code.s3.yandex.net/datasets/final_tickets_events_df.csv
- https://code.s3.yandex.net/datasets/final_tickets_tenge_df.csv

4. Сделать файл `.env` из `.env.example` и вписать туда доступы к базе данных

5. Запустить

```
python3 main.py
```

## Итоги анализа

- После очистки осталось 281 879 заказов и 20 626 пользователей
- Были пользователи с тысячами заказов, скорее всего это боты. Я убрал их по 95 перцентилю
- Повторный заказ делают 59.7% пользователей
- Больше всего пользователей приходят через концерты (44.8%) и с телефона (83%)
- Чаще возвращаются после театра (61.9%) и выставок (63.1%), реже всего после спорта (53.4%)
- С компьютера возвращаются немного чаще, чем с телефона (61.8% и 59.2%)
- Гипотеза 1 не подтвердилась: после спорта возвращаются реже, чем после концертов (53.4% и 60.2%)
- Гипотеза 2 подтвердилась частично: в топ-10 регионов возвращаются чаще (60.9% и 56.7%), но связь слабая
- День недели первого заказа почти не влияет на возврат
- По корреляции с количеством заказов больше всего связаны время между заказами и средняя выручка. Регион, устройство и тип мероприятия почти не связаны

## Рекомендации

1. Работать с пользователем после первой покупки: подборки и напоминания о мероприятиях
2. Больше всего пользователей приходят с телефона и на концерты, поэтому улучшения там дадут самый большой эффект
3. После спорта люди возвращаются реже всего, им можно предлагать другие мероприятия
4. Пользователи с очень дешевым первым заказом возвращаются реже, для них нужно что-то отдельное
5. У театра и выставок хорошее удержание, можно развивать программы лояльности
6. Нужно находить ботов и убирать их из аналитики, потому что они портят метрики
